# thinkEdu · assinatura visual

Livro aberto e gesto de acolhimento, com a criança no centro. Mantém o nome thinkEdu. O símbolo vetorial está em `thinkedu-symbol.svg`; a versão para ícone está em `thinkedu-icon.svg`. Azul #254BFF, laranja #FF754B e verde #E6F581.

O administrativo usa SVG, o aplicativo usa PNG derivado em 256 pixels e o ícone usa PNG de 1.024 pixels. O ícone iOS não tem transparência. A configuração Expo deve gerar os recursos nativos com prebuild ao recriar o projeto.
